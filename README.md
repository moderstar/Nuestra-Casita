# Nuestra Casita

Nuestra Casita is a private household dashboard and organization project.

## Services

- Grocy: groceries, inventory, recipes, chores, and meal planning
- Home Assistant: kitchen tablet dashboard
- Nextcloud: household calendar
- Actual Budget: household budgeting

## Current Progress

- Grocy 4.6 installed
- Locations created
- Quantity units created
- Product groups created
- Stores created
- Kitchen dashboard created in Home Assistant

## Security

This repository must not contain:

- Passwords
- API keys
- Access tokens
- Databases
- Financial transactions
- Private calendar events
- Personal exports
